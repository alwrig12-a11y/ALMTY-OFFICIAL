# ALMTY Official Web Application

The official frontend platform and digital storefront for ALMTY, built with lightweight, modern web tools for high performance, mobile responsiveness, and clean UI/UX.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript
* **Deployment & Hosting:** Vercel 
* **Architecture:** Mobile-first, responsive design

---

## ✨ Features

* **Responsive Layout:** Optimized for desktop, tablet, and mobile browsers.
* **Modern UI:** Custom CSS styling focusing on clean brand aesthetics and smooth user interactions.
* **Optimized Performance:** Fast load times with structured, clean markup and asset management.
